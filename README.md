# Проект для портфолио: школа № 654 имени А. Д. Фридмана

Подготовлена отдельная адаптивная страница проекта и 12 фотографий с понятными именами файлов.

## Состав
- `project-school-654.html` — готовая страница-галерея;
- `images/` — фотографии, используемые страницей.

## Публикация через GitHub
1. Откройте репозиторий https://github.com/monro097/Portfolio- и нажмите **Add file → Upload files**.
2. Загрузите `project-school-654.html` в корень репозитория.
3. Загрузите папку `images` целиком с 12 JPEG-файлами (если интерфейс не принимает папку, создайте `images/` через **Add file → Create new file**, а затем добавьте файлы в эту папку).
4. Сделайте **Commit changes** в ветку `main`.
5. Страница станет доступна по адресу: https://monro097.github.io/Portfolio-/project-school-654.html (обычно через минуту-две после публикации).

Ссылка «На главную портфолио» уже ведёт на главную страницу сайта. Чтобы карточка проекта появилась прямо в секции «Портфолио» на главной, потребуется отдельно добавить ссылку на эту страницу в код главной страницы.
