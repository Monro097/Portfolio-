# Как обновить портфолио на GitHub Pages

Сайт: https://monro097.github.io/Portfolio-/
Репозиторий: https://github.com/monro097/Portfolio-

Архив **portfolio-update-v2.zip** заменяет прежний `portfolio-update.zip`: в нём все файлы сайта, включая новый объект. Сам zip-файл в репозиторий не загружайте, нужны файлы из него.

## Что в архиве
- `index.html` — главная страница. В разделе «Портфолио» три карточки: школа № 654, Технополис Алабушево, Детский центр ГКБ им. М.П. Кончаловского.
- `project-school-654.html` — школа № 654 (12 фото, без подписей).
- `project-technopolis-alabushevo.html` — Технополис Алабушево (3 фото, без подписей).
- `project-detskiy-centr-konchalovskogo.html` — Детский центр ГКБ им. М.П. Кончаловского (8 фото, без подписей; 2019—2023, производитель работ). **Новый.**
- папка `images` — 23 фотографии. Новые файлы: `dc-01` … `dc-08`.

## Вариант 1: прошлый архив ещё не загружали
Загрузите всё из архива: четыре HTML-файла и все фото из папки `images`.

## Вариант 2: прошлый архив уже загружен
Загрузите только новое:
1. `index.html` (заменит старую главную страницу);
2. `project-detskiy-centr-konchalovskogo.html`;
3. файлы `dc-01` … `dc-08` в папку `images`.

## Загрузка с iPhone
1. В приложении «Файлы» нажмите на архив: он распакуется в папку.
2. Откройте репозиторий → **Add file → Upload files**.
3. HTML-файлы загружайте в корень репозитория: выберите в распакованной папке `index.html` и `project-….html`.
4. Фото — внутрь папки `images`. Если папки в репозитории ещё нет: **Add file → Create new file**, в имени введите `images/.gitkeep`, затем **Commit changes**. Откройте `images` → **Add file → Upload files** → выберите фото. Можно несколько сразу; если не получается, загружайте по одному.
5. Нажмите **Commit changes** (ветка `main`).
6. Через 1–2 минуты откройте сайт. Если видна старая версия, обновите страницу без кэша.

Имена файлов менять не нужно: ссылки на сайте привязаны к ним.
